Dora 用户指南

C API 参考

节点 API（dora-node-api-c）

头文件：apis/c/node/node_api.h Crate：dora-node-api-c（以 staticlib 形式构建）

节点 API 供以独立 C 可执行文件形式参与 Dora 数据流的外部进程使用。守护进程负责启动该进程，并设置节点初始化时读取的环境变量。

初始化

init_dora_context_from_env

void *init_dora_context_from_env();

根据守护进程设置的环境变量初始化一个 Dora 节点上下文。成功时返回指向该上下文的不透明指针，失败时返回 NULL。

返回的指针必须传递给后续所有需要上下文参数的节点 API 调用。节点结束时，使用 free_dora_context 释放它。

free_dora_context

void free_dora_context(void *dora_context);

释放之前由 init_dora_context_from_env 创建的上下文。每个上下文必须恰好释放一次。释放后不得再次使用该指针。

事件循环

dora_next_event

void *dora_next_event(void *dora_context);

阻塞等待该节点的下一个事件到来。返回指向该事件的不透明指针；当所有事件流都已关闭时返回 NULL（表示节点应当退出）。

不得直接解引用返回的指针。应使用 read_dora_* 系列函数提取事件类型和负载数据。使用完毕后用 free_dora_event 释放该事件。

free_dora_event

void free_dora_event(void *dora_event);

释放之前由 dora_next_event 返回的事件。每个事件必须恰好释放一次。释放后，该事件指针以及由 read_dora_input_id、read_dora_input_data 派生的所有指针都将失效。

事件检查

read_dora_event_type

enum DoraEventType read_dora_event_type(void *dora_event);

返回给定事件的类型。可能的取值见 DoraEventType。

read_dora_input_id

void read_dora_input_id(void *dora_event, char **out_ptr, size_t *out_len);

从一个 DoraEventType_Input 事件中读取输入 ID。将字符串起始指针写入 *out_ptr，其字节长度写入 *out_len。该字符串是合法的 UTF-8，但不以空字符结尾；应使用 out_len 确定其边界。

如果该事件不是输入事件，则设置 *out_ptr = NULL 且 *out_len = 0。

返回的指针借用自该事件，在调用 free_dora_event 后将失效。

read_dora_input_data

void read_dora_input_data(void *dora_event, char **out_ptr, size_t *out_len);

从一个 DoraEventType_Input 事件中读取原始数据字节。将数据起始指针写入 *out_ptr，其字节长度写入 *out_len。

如果该事件不是输入事件，或该输入不携带数据，则设置 *out_ptr = NULL 且 *out_len = 0。

目前仅支持 UInt8 类型的 Arrow 数组。其他 Arrow 数据类型将导致运行时 panic。未来版本将使用 Arrow C Data Interface 以支持完整的类型。

返回的指针借用自该事件，在调用 free_dora_event 后将失效。

read_dora_input_timestamp

unsigned long long read_dora_input_timestamp(void *dora_event);

以 uint64 值的形式返回输入事件元数据中的混合逻辑时钟时间戳。如果该事件不是输入事件，则返回 0。

输出

dora_send_output

int dora_send_output(
    void *dora_context,
    const char *id_ptr,
    size_t id_len,
    const char *data_ptr,
    size_t data_len
);

将输出数据发送给所有下游订阅者。输出 ID（id_ptr/id_len）必须是与节点在 dataflow YAML 中声明的某个输出相匹配的合法 UTF-8 字符串。数据（data_ptr/data_len）以原始字节形式（UInt8 Arrow 数组）发送。

成功时返回 0，出错时返回 -1。错误会通过 tracing 记录。

如果任一指针参数为 NULL，立即返回 -1。

日志记录

dora_log

int dora_log(
    void *dora_context,
    const char *level_ptr,
    size_t level_len,
    const char *msg_ptr,
    size_t msg_len
);

通过 Dora 日志管道发送一条结构化日志消息。level 和 msg 都必须是合法的 UTF-8 字符串。

合法的日志级别："error"、"warn"、"info"、"debug"、"trace"。

成功时返回 0，出错时返回 -1。如果任一指针参数为 NULL，立即返回 -1。

枚举

DoraEventType

enum DoraEventType {
    DoraEventType_Stop,        // Graceful shutdown requested
    DoraEventType_Input,       // New input data available
    DoraEventType_InputClosed, // An input stream was closed
    DoraEventType_Error,       // An error occurred
    DoraEventType_Unknown,     // Unrecognized event type
};

算子 API（dora-operator-api-c）

头文件：apis/c/operator/operator_api.h、apis/c/operator/operator_types.h Crate：dora-operator-api-c

算子 API 供加载到 Dora 运行时进程中的共享库（.so/.dylib/.dll）使用。与节点不同，算子没有自己的 main 函数，而是导出三个函数，由运行时在相应的生命周期节点调用。

operator_types.h 头文件由 safer-ffi 自动生成，定义了所有与 C 兼容的结构体和枚举类型。

生命周期函数

dora_init_operator

DoraInitResult_t dora_init_operator(void);

在运行时加载该算子时调用一次。分配并初始化任何算子状态，然后通过 operator_context 字段将其返回。运行时会在后续每次调用时将该指针传回。

成功时返回一个 DoraInitResult_t，其中 .result.error = NULL。

dora_drop_operator

DoraResult_t dora_drop_operator(void *operator_context);

在该算子被卸载时调用一次。释放与 operator_context 相关的所有资源。

成功时返回一个 DoraResult_t，其中 .error = NULL。

事件处理

dora_on_event

OnEventResult_t dora_on_event(
    RawEvent_t *event,
    const SendOutput_t *send_output,
    void *operator_context
);

每当该算子收到一个事件时，运行时都会调用此函数。检查 event 的各字段以确定事件类型：

字段含义
event->input != NULL有新的输入到来
event->stop == true请求优雅关闭
event->error.ptr != NULL发生了错误（UTF-8 字符串位于 error.ptr/error.len）
event->input_closed.ptr != NULL某个输入流已关闭（输入 ID 位于 input_closed.ptr/input_closed.len）

使用 send_output 向下游节点发送数据（参见 dora_send_operator_output）。返回一个带有合适 DoraStatus_t 的 OnEventResult_t，以控制算子的生命周期。

输入读取

dora_read_input_id

char *dora_read_input_id(const Input_t *input);

返回一个新分配的以空字符结尾的字符串，包含输入 ID。调用者必须使用 dora_free_input_id 释放它。

dora_read_data

Vec_uint8_t dora_read_data(Input_t *input);

将输入数据读取为字节数组。会消费该输入底层的 Arrow 数组（每个事件的数据只能读取一次）。如果输入没有数据，或数据已被消费，则返回 Vec_uint8_t，其 .ptr = NULL。

调用者必须使用 dora_free_data 释放返回的数据。

输出发送

dora_send_operator_output

DoraResult_t dora_send_operator_output(
    const SendOutput_t *send_output,
    const char *id,
    const uint8_t *data_ptr,
    size_t data_len
);

将输出数据发送给下游订阅者。id 必须是一个以空字符结尾的字符串，并匹配算子已声明的某个输出。数据（data_ptr/data_len）在内部会被转换为 UInt8 Arrow 数组。

成功时返回 DoraResult_t，其 .error = NULL。

内存管理

算子 API 会分配内存，调用者必须使用对应的函数来释放：

分配来源释放函数
dora_read_input_iddora_free_input_id
dora_read_datadora_free_data
 
void dora_free_input_id(char *input_id);
void dora_free_data(Vec_uint8_t data);

未调用这些函数会导致内存泄漏。请不要对这些分配使用 free()——它们由 Rust 运行时分配，必须通过该 API 释放。

结构体

Vec_uint8_t

typedef struct Vec_uint8 {
    uint8_t *ptr;
    size_t len;
    size_t cap;
} Vec_uint8_t;

一个由 Rust 分配的字节向量。从 ptr 开始访问 len 字节。请不要修改 cap。使用 dora_free_data 释放。

DoraResult_t

typedef struct DoraResult {
    Vec_uint8_t *error;  // NULL on success, points to error string on failure
} DoraResult_t;

通用结果类型。NULL 错误指针表示成功。若非 NULL，则该错误指针包含一条 UTF-8 编码的错误信息。

DoraInitResult_t

typedef struct DoraInitResult {
    DoraResult_t result;
    void *operator_context;  // opaque pointer to operator state
} DoraInitResult_t;

由 dora_init_operator 返回。成功时，result.error 为 NULL，operator_context 持有算子状态指针。

OnEventResult_t

typedef struct OnEventResult {
    DoraResult_t result;
    DoraStatus_t status;
} OnEventResult_t;

由 dora_on_event 返回。同时包含一个错误/成功结果，以及一个用于控制算子生命周期的状态码。

RawEvent_t

typedef struct RawEvent {
    Input_t *input;           // non-NULL when this is an input event
    Vec_uint8_t input_closed; // non-empty when an input stream closed
    bool stop;                // true when shutdown is requested
    Vec_uint8_t error;        // non-empty on error
} RawEvent_t;

表示传递给算子的一个事件。多个字段可能同时被设置；请按优先级顺序检查它们。

Input_t

typedef struct Input Input_t;  // opaque

表示输入事件数据的不透明类型。使用 dora_read_input_id 和 dora_read_data 提取其内容。

Output_t

typedef struct Output Output_t;  // opaque

由 dora_send_operator_output 内部使用的不透明类型。用户代码不会直接创建它。

SendOutput_t

typedef struct SendOutput {
    ArcDynFn1_DoraResult_Output_t send_output;
} SendOutput_t;

传给 dora_on_event 的回调句柄。将其传给 dora_send_operator_output 以发送数据。请不要在当前 dora_on_event 调用的作用域之外保存它。

Metadata_t

typedef struct Metadata {
    Vec_uint8_t open_telemetry_context;
} Metadata_t;

包含 OpenTelemetry 追踪上下文字符串的事件元数据。

算子枚举

DoraStatus_t

enum DoraStatus {
    DORA_STATUS_CONTINUE = 0,  // Keep running
    DORA_STATUS_STOP     = 1,  // Stop this operator
    DORA_STATUS_STOP_ALL = 2,  // Stop the entire dataflow
};
typedef uint8_t DoraStatus_t;

在 OnEventResult_t 中返回，用于在处理完一个事件后控制算子的生命周期。

节点示例

一个完整的 C 节点，接收定时器滴答并发送输出消息：

#include <stdio.h>
#include <string.h>
#include "node_api.h"

int main() {
    void *ctx = init_dora_context_from_env();
    if (ctx == NULL) {
        fprintf(stderr, "failed to init dora context\n");
        return 1;
    }

    for (int i = 0; i < 100; i++) {
        void *event = dora_next_event(ctx);
        if (event == NULL)
            break;  // all streams closed

        enum DoraEventType ty = read_dora_event_type(event);

        if (ty == DoraEventType_Input) {
            char *id;
            size_t id_len;
            read_dora_input_id(event, &id, &id_len);

            // Send a response
            char out_id[] = "message";
            char out_data[64];
            int out_len = snprintf(out_data, sizeof(out_data),
                                   "iteration %d", i);

            dora_send_output(ctx, out_id, strlen(out_id),
                              out_data, out_len);
        } else if (ty == DoraEventType_Stop) {
            free_dora_event(event);
            break;
        }

        free_dora_event(event);
    }

    free_dora_context(ctx);
    return 0;
}

该节点的 dataflow YAML：

nodes:
  - id: c_node
    path: build/c_node
    inputs:
      timer: dora/timer/millis/100
    outputs:
      - message

算子示例

一个完整的 C 算子，读取输入、维护状态并发送输出：

#include "operator_api.h"
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

DoraInitResult_t dora_init_operator(void) {
    // Allocate operator state (a simple counter)
    int *counter = (int *)calloc(1, sizeof(int));

    DoraInitResult_t result = {.operator_context = counter};
    return result;
}

DoraResult_t dora_drop_operator(void *operator_context) {
    free(operator_context);
    DoraResult_t result = {.error = NULL};
    return result;
}

OnEventResult_t dora_on_event(
    RawEvent_t *event,
    const SendOutput_t *send_output,
    void *operator_context)
{
    OnEventResult_t result = {.status = DORA_STATUS_CONTINUE};
    int *counter = (int *)operator_context;

    if (event->input != NULL) {
        char *id = dora_read_input_id(event->input);
        Vec_uint8_t data = dora_read_data(event->input);

        if (data.ptr != NULL) {
            *counter += 1;
            printf("received input '%s', counter: %d\n", id, *counter);

            // Send counter value as string
            char buf[64];
            int len = snprintf(buf, sizeof(buf), "count=%d", *counter);
            result.result = dora_send_operator_output(
                send_output, "counter", (uint8_t *)buf, len);

            dora_free_data(data);
        }

        dora_free_input_id(id);
    }

    if (event->stop) {
        result.status = DORA_STATUS_STOP;
    }

    return result;
}

该算子的 dataflow YAML：

nodes:
  - id: runtime-node
    operators:
      - id: c_operator
        shared-library: build/operator
        inputs:
          data: source_node/output
        outputs:
          - counter

构建与链接

节点（静态库）

C 节点链接的是 dora-node-api-c，它以静态库形式构建。

步骤 1：构建静态库

cargo build -p dora-node-api-c --release

这会生成 target/release/libdora_node_api_c.a（在 Windows 上为 .lib）。

步骤 2：编译并链接

clang node.c -ldora_node_api_c -L ../../target/release -o build/c_node <FLAGS>

平台相关的链接器标志：

平台标志
Linux-lm -lrt -ldl -pthread
macOS-framework CoreServices -framework Security -lSystem -lresolv -lpthread -lc -lm
Windows-ladvapi32 -luserenv -lkernel32 -lws2_32 -lbcrypt -lncrypt -lschannel -lntdll -liphlpapi -lcfgmgr32 -lcredui -lcrypt32 -lcryptnet -lfwpuclnt -lgdi32 -lmsimg32 -lmswsock -lole32 -lopengl32 -lsecur32 -lshell32 -lsynchronization -luser32 -lwinspool -Wl,-nodefaultlib:libcmt -D_DLL -lmsvcrt

在 Windows 上，请为输出文件添加 .exe 扩展名。

算子（共享库）

C 算子被编译为共享库，由 Dora 运行时在启动时加载。

步骤 1：编译为目标文件

clang -c operator.c -o build/operator.o -fdeclspec -fPIC

在 Windows 上省略 -fPIC。

步骤 2：链接为共享库

# Linux
clang -shared build/operator.o -o build/liboperator.so

# macOS
clang -shared build/operator.o -o build/liboperator.dylib

# Windows
clang -shared build/operator.o -o build/operator.dll

步骤 3：在 dataflow YAML 中引用

operators:
  - id: c_operator
    shared-library: build/operator   # without lib prefix or extension
    inputs:
      data: source/output
    outputs:
      - result

shared-library 路径省略了平台相关的前缀（lib）和扩展名（.so/.dylib/.dll）。运行时会为当前平台解析出正确的文件。

Include 路径

Node API 的头文件位于 apis/c/node/node_api.h。Operator API 的头文件位于 apis/c/operator/operator_api.h 和 apis/c/operator/operator_types.h。请相应地调整你的 include 路径：

# Node
clang -I path/to/dora/apis/c/node node.c ...

# Operator
clang -I path/to/dora/apis/c/operator operator.c ...

C++ 兼容性

两个头文件都带有 extern "C" 保护（在算子头文件中），或使用与 C 兼容的声明（在节点头文件中），因此可以直接从 C++ 源文件中包含它们。
